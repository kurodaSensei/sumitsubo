# Roadmap

Where Sumitsubo is going. Each item is a GitHub issue; milestones group them by version. Priorities move with feedback, so comment on the issues you care about.

## Shipped

| Version | What |
|---|---|
| **0.6** | `npx sumitsubo` installer (install, doctor, update with repair, uninstall, sandbox); installs without SSH keys; one-merge releases with npm trusted publishing; CI installs from scratch on every push |
| 0.5 | Budgeted, receipt-based reviews; scope check; model profiles; one output contract; `/sumi:doctor` |
| 0.1–0.4 | Core workflow, design layer, four stack packs, companions as dependencies, model routing |

See [CHANGELOG.md](CHANGELOG.md) for details.
